# macOS close-to-menu-bar / Linux development baseline

Date: 2026-10-02. Source base: `0405d68`, plus this lifecycle checkpoint.
This report is a narrow native lifecycle gate, not macOS release completion.

## Implemented

- Pinned original `_onClose` already prevents window destruction and calls hide.
  A project-owned Darwin-only adapter now binds that main window at its exact
  close-registration anchor. Hide removes Dock identity; show/restore reinstates
  it. The original tray, activate, second-instance, recorder and Quit paths are
  retained. No helper/HUD/test window controls the Dock.
- Native hiddenInset frame controls are retained on Darwin. Original application
  View menu gains native Close Window / Command-W on Darwin only.
- Show is asynchronous; a later close is reconciled after it settles. Timers are
  canceled on reopen/quit. Minimize keeps Dock. Windows/Linux behavior is unchanged.
- Pinned Electron 43.2 `DockHide` ignores calls within a second of `DockShow`,
  unlike the current API documentation's repeated-hide wording. Guard both last
  show/hide with 1100 ms. No global security/signing/TCC changes.

Primary sources:
[pinned Electron implementation](https://github.com/electron/electron/blob/v43.2.0/shell/browser/browser_mac.mm#L478),
[Dock API](https://www.electronjs.org/docs/latest/api/dock).
The pinned `DockIsVisible` checks regular activation policy; the native AppKit
read-only probe uses the same policy and reports only installed Medal's PID and
count of its on-screen normal windows, never screen pixels or other app details.

## Failed/ambiguous attempts retained, not promoted to passes

- Dock accessibility inventory timed out (`-10005`); used the read-only AppKit
  identity probe, not a guessed Dock screenshot or other UI-control mechanism.
- `cua.computer.launch_app` is unavailable on this Mac provider. Exact path
  `cua.getApp` and normal Finder Open are the supported routes.
- Initial automated AX inspection after close reactivated Medal; the retained
  `dock-20261002-final-closed.json` is regular, not a background pass. Observe
  Finder after close to avoid the instrumentation reopening the target.
- Automation's window-sharing indicator sometimes obscures native traffic
  lights. The actual red button became available after ordinary Finder reopen;
  the final red-close test then passed on the real control.
- Finder selection follows the old inode across an atomic app swap. Its selected
  label still looked like Medal but its URL resolved to the preserved backup.
  Exact-URL checking refused that Open; no duplicate old app launched. Navigating
  through current `/Applications/Medal.app/Contents` and up restored the exact
  current app selection. Do not reopen by ambiguous display name/backup selection.
- Native probe intentionally exits 1 when no exactly installed host exists;
  the clean-Quit empty-host result is expected, not a failed capture test.

## Linux assessment

The verified shared/native local workflow now supplies a useful Linux
development baseline. Begin from `0405d68` or this checkpoint, retain Mac
regression coverage, and follow the current `HANDOFF_LINUX.md` / Linux brief.
This does not mean Medal works fully on Mac: microphone/device lifecycle,
PTT/feedback/session/recovery, camera/HDR, sustained timing/performance and
release packaging remain open. No Linux hardware/compositor/service acceptance
is claimed; its portal, PipeWire and encoder adapters require native testing.
