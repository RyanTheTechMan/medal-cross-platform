# M3.8l targeted window capture

Date: 2026-09-19

This gate verifies the normal authenticated imported Medal path after replacing
the display-anchored application filter with ScreenCaptureKit's
`initWithDesktopIndependentWindow:` filter. The old path selected a monitor;
the macOS capture indicator showed that monitor and the encoded video contained
only a cursor over black pixels. The new path resolves the largest visible
`SCWindow` owned by the PID-aware target and follows that window independently
of its display. A display+including-application filter remains only as a
bounded fallback during a window recreation/fullscreen transition.

## Restart persistence follow-up

The signed app was terminated by its exact Electron bundle path and relaunched
once through `/Applications/Medal.app`. After reconnecting the native helper,
the 0:31 Minecraft row remained first in the original library with its
thumbnail and unchanged 74.4 MB on-device file. Opening that row after restart
visibly rendered the Minecraft menu and filmstrip again. This establishes the
normal local persistence/playback leg for this clip; a separate file hash check
uses the SHA-256 artifact in this directory.
