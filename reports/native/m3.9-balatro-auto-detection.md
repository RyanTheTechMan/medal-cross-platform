# M3.9 Balatro automatic detection

Date: 2026-09-20

## Diagnosis

Balatro was already being enumerated by the native macOS process adapter. The
pre-fix diagnostic contained a live candidate with:

```text
applicationName=Balatro
bundleIdentifier=com.Balatro.localthunk
executableName=love
windowCount=16
```

The automatic selector nevertheless wrote `decision=no_supported_candidate`.
The cause was an overly narrow native candidate predicate that accepted only
the two games used during the first M3 classification gate (A Dance of Fire and
Ice and Minecraft). This was a native discovery limitation, not a Screen
Capture permission or Medal account failure.

## Correction

The helper now recognizes visible-window processes launched from common game
distribution roots (`Steam/steamapps/common`, Epic Games, GOG Games, Riot
Games, and Battle.net) without maintaining a local game database. The original
authenticated Medal path remains authoritative: the imported client sends the
candidate through `/games/requests`, searches Medal's categories, and returns
the real game request/category metadata. Ordinary regular applications remain
available in the manual chooser but are not auto-targeted by this native
launch-origin filter.

## Live evidence

Balatro was left running from Steam while the rebuilt signed app used the
isolated authenticated profile. No manual process selection was performed. The
actual imported client log recorded this sequence:

```text
targetProcess request
nativePort.gameClassification notification
gameStarted: categoryId 1uwwJ3M9jaW / Balatro
captureStarted: categoryId 1uwwJ3M9jaW / Balatro
gameState: CATEGORY context with members=[]
```

The raw local observation is retained at
`reports/native/m3.9-balatro-auto-detection-live.log`; it is not committed
because it contains ordinary local-account/runtime logging. The recorder also
reported `audio-device-access-denied` during this observation because the
current microphone/TCC setting was unavailable. That is a separate microphone
gate and does not invalidate the successful Balatro process/category flow.
